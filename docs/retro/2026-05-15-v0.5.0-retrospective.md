# Retrospective — shopping-cart-infra v0.5.0

**Date:** 2026-05-15
**Milestone:** Bug fixes — Keycloak LDAP mappers + ArgoCD Istio routing
**PR:** #55 — merged to main
**Participants:** Claude, Codex, Copilot, ai-review (rigor-cli)

## What Went Well
- ai-review (rigor-cli) caught the dead realm JSON mapper block before merge — saved a silent broken state on every cluster rebuild
- Copilot auto-reviewed all 13 files on first push; findings were substantive (Python indentation, kustomization.yaml conflict, idempotency gap)
- Reconcile hook script (`create_mapper_if_missing`) is correct and idempotent after two rounds of fixes
- Spec-first discipline held: both bugs had `docs/bugs/` specs before any code was written

## What Went Wrong
- Codex added a dead `"components"` block to `realm-shopping-cart.json` using a Keycloak-invalid format — `partialImport` doesn't import UserStorageProvider components at all
- Copilot's Python indentation bug was suppressed as "low confidence" but was in fact critical (mappers would never be created)
- `kustomization.yaml` was created and then deleted in the same PR — could have been caught earlier in the spec
- Three rounds of Codex commits were needed before all Copilot findings were addressed

## Process Rules Added
- ai-review (rigor-cli `bin/ai-review`) added as a pre-merge quality gate alongside Copilot
- Resolve Copilot threads via GraphQL after each fix round (`resolveReviewThread` mutation)

## Decisions Made
- LDAP mappers are managed exclusively by the reconcile hook script; realm JSON is not a reliable bootstrap path for UserStorageProvider components
- ArgoCD routing: `directory:` mode Application with no `kustomization.yaml` in path — avoids ArgoCD source-type auto-detection conflict
- ArgoCD URL must be `http://` (not `https://`) because ArgoCD runs `--insecure`

## Theme
Two silent failures — missing Istio routing and broken LDAP mapper bootstrap — surfaced only under live cluster validation. The fix required three code review cycles (Copilot × 2, ai-review × 2) and caught a deeper API contract issue: Keycloak's `partialImport` endpoint silently ignores component types. The reconcile hook script is now the authoritative mapper source.
