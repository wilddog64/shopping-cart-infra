# v0.5.1 Retrospective — 2026-05-15

## What Went Well

- **Codex implemented the python3 → kcadm.sh fix correctly on first attempt** — the hook now uses only bash/grep/sed and server-side `kcadm.sh -q` query parameters, eliminating all JSON parsing logic
- **Copilot caught the `|| echo 0` double-output bug before merge** — prevented an integer validation error in the existing-mapper check
- **kcadm.sh server-side query parameters cleanly replaced python3 JSON parsing** — `-q type=`, `-q parent=`, `-q name=` filters eliminate YAML/JSON roundtrips entirely
- **Thread resolution via GraphQL worked reliably** — Copilot review threads resolved cleanly

## What Went Wrong

- **`|| echo 0` was incorrect in the original spec** — the bug: `grep -c` prints `0` AND exits 1 when zero matches are found; inside `$(...)` with `set -o pipefail`, the `||` operator catches the exit 1 and runs `echo 0`, resulting in `"0\n0"` (two lines), making `existing` an invalid integer when compared
- **Required a follow-up commit (`6fa86ce`) to fix before PR could merge** — the spec should have specified `|| true` instead

## Decisions Made

- **`grep -c ... || true` is the correct pattern** — when `grep -c` may return 0 matches inside `$(...)` with `set -o pipefail`, catch the exit code without producing extra output
- **`kcadm.sh -q` server-side filtering eliminates all need for python3/jq** — cleaner, faster, and compatible with ubi9-minimal
- **`quay.io/keycloak/keycloak:24.0` (ubi9-minimal) has no Python** — any future scripts in this container must use only bash builtins, grep, sed, awk, and kcadm.sh

## Theme

The v0.5.1 milestone fixed the root cause of SSO login failures: the Keycloak reconcile hook relied on `python3`, which is not available in the ubi9-minimal container image. By replacing both python3 calls with `kcadm.sh -q` server-side query parameters and grep/sed, the hook now runs entirely with tools that ship in the container. A follow-up fix corrected a `|| echo 0` pattern that would have produced an invalid integer for the mapper-exists check.

## Impact

- Keycloak reconcile hook is now portable across all ubi-minimal images
- No external Python dependencies in the cluster
- Faster query execution via server-side filtering
- Hook can run in restricted containers with minimal installed packages
